# Проверки значений

Базовая библиотека предикатов для безопасной работы с `unknown`, отсутствующими значениями, примитивами, массивами
и объектами. Подключай её, когда нужны повторяемые базовые проверки, а эквивалентного общего решения ещё нет.

## Подключение

1. Найди существующие проверки и сравни их контракты с таблицей ниже. Используй подходящие аналоги вместо второго набора.
2. Если аналога нет, выбери место общего модуля по архитектуре проекта.
3. Перенеси в него [реализацию](value-predicates.ts) и [публичную точку входа](index.ts). Документацию копировать в код
   приложения не требуется.
4. Подключи потребителей через публичный путь модуля и проверь типы и поведение на граничных значениях.

Минимальное содержимое модуля:

```text
value-predicates/
├── index.ts
└── value-predicates.ts
```

Абсолютное размещение и путь импорта определяет проект. Сохрани `index.ts` как публичный API; если проект закрепляет
другое имя точки входа, адаптируй его по правилам проекта. Не импортируй файл реализации глубоким путём.

Библиотека не зависит от React, браузера или конкретной структуры слоёв. Она содержит только универсальные проверки
формы значений. Проверки DTO, ответов API и предметных сущностей, например `isOrder` или `isCity`, размещай у владельца
соответствующих данных.

## Состав и выбор предиката

| Сценарий | Предикат |
| --- | --- |
| Исключить `null` и `undefined`, сохранив `0`, `false` и `''` | `isDefined` |
| Проверить `null` или `undefined` | `isNotDefined` |
| Проверить строку | `isString` |
| Проверить конечное число | `isNumber` |
| Проверить логическое значение | `isBoolean` |
| Проверить непустую строку, содержащую непробельные символы | `isNonEmptyString` |
| Проверить массив без проверки элементов | `isArray` |
| Проверить непустой типизированный массив | `isNonEmptyArray` |
| Считать `null`, `undefined` или `[]` пустым списком | `isEmptyArray` |
| Проверить массив из внешнего `unknown` вместе с каждым элементом | `isArrayOf(value, itemGuard)` |
| Прочитать поле неизвестного объекта | `isRecord` + `hasOwn` + предикат поля |
| Проверить значение из объединения литералов | `isOneOf` |

`isEmptyArray` и `isNonEmptyArray` принимают уже типизированный массив либо `null`/`undefined`. Они не подтверждают
тип элементов внешнего `unknown`: для этого используй `isArrayOf`.

Прямой `.length` допустим, когда нужен числовой размер, проверка длины строки или индексный цикл. Для логического
решения о пустом списке используй `isEmptyArray` или `isNonEmptyArray`.

## Предметная проверка

Собирай предметный предикат из базовых проверок рядом с владельцем данных:

```ts
/**
 * Данные заказа.
 */
type Order = {
  /** Идентификатор заказа. */
  id: string

  /** Название заказа. */
  title: string
}

/**
 * Проверяет значение на соответствие заказу.
 */
const isOrder = (value: unknown): value is Order => {
  return (
    isRecord(value) &&
    hasOwn(value, 'id') &&
    isString(value.id) &&
    hasOwn(value, 'title') &&
    isString(value.title)
  )
}
```

Не заменяй проверку утверждением через `as`. Предикат должен проверить каждое поле, на котором основан суженный тип.

## Проверка

- Библиотека добавлена только при отсутствии эквивалентного общего решения.
- Потребители импортируют предикаты через публичную точку входа модуля.
- Базовые предикаты не содержат предметных правил.
- Предметные проверки размещены рядом с владельцами данных.
- `unknown` проверяется до чтения и использования полей.
- `0`, `false` и `''` не смешиваются с `null` и `undefined`.
- Для внешнего массива проверяется каждый элемент, а не только наличие массива.
