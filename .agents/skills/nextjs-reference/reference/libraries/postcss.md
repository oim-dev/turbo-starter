# PostCSS и CSS Modules

Next.js поддерживает CSS Modules самостоятельно. Для общего канона вложенности и именованных медиавыражений
настрой один набор PostCSS-плагинов. Не добавляй Vite и отдельный плагин CSS Modules.

## Установка и конфигурация

Для нового приложения с npm:

```bash
npm install --save-dev postcss @csstools/postcss-global-data postcss-custom-media postcss-nesting autoprefixer
```

При другом пакетном менеджере используй эквивалент. Если обработка уже настроена, сначала сравни её обязанности
с этой конфигурацией; не накладывай второй преобразователь вложенности или медиавыражений.

`postcss.config.mjs` в корне приложения:

```js
export default {
  plugins: {
    '@csstools/postcss-global-data': {
      files: ['src/ui/themes/styles/media.css']
    },
    'postcss-custom-media': {},
    'postcss-nesting': {},
    autoprefixer: {}
  }
}
```

Порядок обязателен: общие определения → медиавыражения → вложенность → префиксы.
Пользовательский конфиг заменяет стандартный набор PostCSS Next.js, поэтому перечисли нужную обработку явно.
Поддерживаемые браузеры задай одним Browserslist приложения.

## Файлы темы

```text
ui/themes/
├── client.ts
├── styles.css                    # публичное подключение
└── styles/
    ├── media.css                 # только определения для сборки
    └── variables.css             # общие переменные приложения
```

В `styles.css` подключи `./styles/variables.css` и необходимые базовые правила документа. Не импортируй туда
`media.css`: его определения передаются плагином каждому обрабатываемому файлу. Не подключай CSS Modules глобально.

Шкала `media.css` согласуется с дизайном и контрольными точками Mantine. Исходный вариант при отсутствии требований:

```css
@custom-media --sm (min-width: 36em);
@custom-media --md (min-width: 48em);
@custom-media --lg (min-width: 62em);
@custom-media --xl (min-width: 75em);
```

Значения цветов и размеров Mantine используй через его CSS-переменные. В `variables.css` добавляй только реальные
проектные значения с общим смыслом; не создавай вторую тему с копиями всех значений библиотеки.
Если проектных переменных пока нет, не оставляй пустой файл и импорт.

Этот набор не включает синтаксис `postcss-preset-mantine` вроде его специальных миксинов. Не копируй такие примеры
в проект без соответствующего преобразователя; используй поддерживаемые CSS-переменные и каноны `postcss-styleguide`.

## Проверка

Собери приложение выбранным сборщиком Next.js. Проверь раскрытие вложенности и `@media (--md)`, присутствие общих
стилей и отсутствие необработанных директив в итоговом CSS. Проверь один адаптивный компонент в браузере.
