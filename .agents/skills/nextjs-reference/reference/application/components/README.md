# Создание компонентов

Сначала определи владельца по [архитектуре](../architecture/README.md), затем среду по [SSR](../rendering/README.md).
Наличие JSX не делает компонент универсальным UI, а наличие запроса не делает его клиентским.

1. Проверь готовый компонент проекта и Mantine по [интерфейсу](../ui/README.md).
2. Определи минимальные свойства, действия и место состояния.
3. Выбери внутренний компонент без фасета либо самостоятельный юнит с подтверждённой ответственностью.
4. Создай файлы по [генерации TSX](tsx-generation.md).
5. Примени `ts-styleguide`, `tsx-styleguide` и для CSS — `postcss-styleguide`.
6. Подключи внутренний компонент относительным импортом, самостоятельный — через нужный фасет.
7. Проверь серверное отображение, свойства, интерактивность и гидратацию.

## Форма файлов

```text
component-name/
├── component-name.tsx
├── types/
│   └── component-name-props.type.ts
└── styles/
    └── component-name.module.css
```

У самостоятельного юнита добавляется необходимый фасет. У внутреннего компонента фасета нет.
Компонент имеет собственную папку, даже если после адаптации в ней остаётся только TSX. Тип свойств размещай в
`types/`; CSS Module оставляй лишь при наличии собственных стилей. JSDoc описывает назначение и применение.

Для экранов и каркасов после генерации используй `.screen.tsx` и `.layout.tsx`, согласовав импорты и имена.
Специальные файлы Next.js сохраняют свои имена.

## Серверная и клиентская часть

Чистая разметка остаётся без директив. Асинхронное серверное чтение находится в серверной реализации владельца.
Хуки и события выделяются в небольшую клиентскую часть; её исходный файл или публичная точка входа содержит
`'use client'`. Не помечай весь домен клиентским ради одного поля формы.

Тип `ComponentPropsWithoutRef` удобен внутри одной среды, но может включать обработчики событий. При пересечении
RSC-границы сузь контракт до реально передаваемых сериализуемых свойств. Тип DOM не отменяет ограничений React.

Компонент без собственного DOM не получает фиктивные `RootAttrs`, `div` и пустой CSS. Provider или граница могут
вернуть готовые `children`. Серверный слот передаётся как `ReactNode`, а не как функция построения серверного JSX.

Локальные части страницы оставляй у экрана. Поднимай в `widgets` только при самостоятельном результате и реальных
потребителях. Не создавай вложенный юнит, если ему необходимы внутренние типы, хуки или операции родителя.
