# Интерфейс

Для нового приложения используй Mantine. Сначала ищи готовое решение проекта, затем компонент Mantine, затем
собственную композицию. Не создавай заново модальные окна, поля и управление фокусом, если библиотека уже решает задачу.

Универсальные визуальные возможности принадлежат `ui`, предметные — соответствующему домену, локальные блоки —
своему экрану или каркасу. Вызов серверной операции не переносит весь экран в домен.

## Порядок

1. Подключи тему и SSR по [Mantine](../../libraries/mantine.md).
2. Выбери компонент и его публичные свойства. Используй встроенные состояния, размеры и семантику.
3. Для настройки внешнего вида используй Styles API и CSS Module владельца по [стилям](../styling/README.md).
4. Для события или свойства с функцией создай узкую клиентскую обёртку. Передавай из серверного родителя данные и
   готовые слоты, а не обычные функции.
5. Создавай собственную обёртку лишь при проектном визуальном контракте, повторяемом поведении или необходимой
   границе RSC. Не оборачивай каждый импорт Mantine механически.
6. Проверь доступное имя, клавиатуру, фокус и SSR.

Mantine-компоненты являются клиентскими, но предварительно отображаются на сервере. Их использование не требует
директивы `'use client'` у всей страницы. Из Server Component импортируй отдельные составные компоненты, например
`AppShellMain`; обращение `AppShell.Main` оставь внутри клиентского графа.
