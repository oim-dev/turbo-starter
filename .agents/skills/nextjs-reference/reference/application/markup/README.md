# Вёрстка по макету

1. Выдели смысловые области, данные, действия и состояния. Уточни реальные тексты, изображения и правила адаптивности.
2. Определи серверное содержимое и небольшие интерактивные части по [SSR](../rendering/README.md).
3. Назначь владельца каждой области по [архитектуре](../architecture/README.md). Локальная часть экрана остаётся внутри
   экрана; повторяемость внешнего вида сама по себе не делает её предметным юнитом.
4. Найди готовые компоненты проекта и Mantine, затем создай недостающие через [генератор](../components/tsx-generation.md).
5. Построй семантический DOM: заголовки, области, списки, кнопки действий, ссылки переходов и подписанные поля.
6. Реализуй CSS Modules по [стилям](../styling/README.md); базовая разметка не зависит от размера браузерного окна.
7. Подготовь состояния загрузки, пустого результата, ошибки, длинного текста и недоступного действия.
8. Проверь серверный HTML, гидратацию, клавиатуру и размеры макета, включая промежуточные ширины.

Для фотографий и содержательных растровых изображений используй `next/image` с подходящими размерами и `sizes`.
Для декоративных фонов и SVG-спрайтов используй их собственные механизмы. Не превращай всё в клиентский компонент
ради оптимизации изображений или одного интерактивного элемента.

Не подменяй реальные данные макета случайными значениями во время отображения. Заглушки ожидания должны сохранять
разумные размеры блоков и не дублировать доступное описание готового содержимого.
