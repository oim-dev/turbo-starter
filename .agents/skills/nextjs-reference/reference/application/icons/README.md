# Иконки

Используй принятый в проекте набор для обычных интерфейсных символов. Собственные SVG объединяй через
`@gromlab/svg-sprites` по [инструкции App Router](../../libraries/svg-sprites.md); перед изменением интеграции загрузи
`svg-sprites-ru`.

1. Определи владельца набора: общие иконки — визуальный юнит, узкие предметные — их действительный владелец.
2. Проверь точные сборщики команд `dev` и `build` и выбери соответствующий режим генерации.
3. Добавь исходный SVG и запусти генерацию до проверки типов или сборки.
4. Импортируй компонент через фасет владельца. Не собирай идентификатор `<use>` вручную.
5. Размер и цвет задавай CSS либо публичными свойствами; для многоцветных SVG используй `--icon-color-N`.
6. Для декоративного символа передай `aria-hidden`, для самостоятельного — доступное имя. Действие принадлежит
   кнопке или ссылке, а не самому SVG.

Generated-компонент режима Next.js совместим с Server Components. Не добавляй `'use client'` только ради иконки.
Проверь URL спрайта в производственной сборке и при настроенном `basePath`.
