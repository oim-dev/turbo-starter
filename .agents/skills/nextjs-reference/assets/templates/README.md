# Начальный набор шаблонов

Этот каталог содержит самостоятельные шаблоны Next.js-профиля для `@gromlab/template-file-generator@0.3.1`.
Установи `ui-component/` и `ui-unit/` в `.templates/` приложения вместе с этой инструкцией, только если у приложения
ещё нет своего набора. Не перезаписывай существующие шаблоны.

- `ui-component <name> <path>` создаёт внутреннюю реализацию без публичного фасета.
- `ui-unit <name> <path>` создаёт тот же начальный DOM-каркас и фасет `index.ts`.
- Обязательная переменная одна: позиционное `name` в `kebab-case`.
- Шаблоны используют React, TypeScript, CSS Modules и `clsx`.
- Директивы среды намеренно отсутствуют: чистая заготовка пригодна для серверного и клиентского графов.

Запускай из корня приложения, например:

```bash
npm run create -- ui-component profile-summary src/compositions/screens/account/ui
```

Прочитай шаблон перед запуском. После генерации адаптируй свойства, корневой элемент, JSDoc и стили. Если компонент
не имеет DOM, удали заготовку обёртки и её CSS. Если самостоятельному юниту нужен серверный либо клиентский фасет,
замени начальный `index.ts` соответствующим фасетом и защитой среды по `nextjs-reference`.

Команда не является способом обновления существующего компонента. При коллизии проверь целевые файлы и имя;
не добавляй `--overwrite` автоматически.
