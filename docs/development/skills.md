# Работа с проектными скиллами

Для управления скиллами используется CLI [skills](https://github.com/vercel-labs/skills).
Все команды выполняйте из корня репозитория. Для текущей версии CLI требуется
Node.js 22.20.0 или новее.

- `skills-lock.json` хранит список скиллов, их источники, пути и хеши содержимого.
  Этот файл нужно хранить в Git.
- `.agents/skills/` содержит установленные скиллы и добавлен в `.gitignore`.
- `.claude/skills/` содержит ссылки или копии для Claude Code и также добавлен
  в `.gitignore`.

## Установить все проектные скиллы

Для первоначальной подготовки проекта выполните:

```bash
pnpm install
pnpm setup
```

`setup` восстанавливает скиллы из `skills-lock.json`, затем собирает профили агентов
для OpenCode, Claude Code и Codex. Установленные скиллы, генерируемые профили,
конфигурации сред и `agents-lock.json` исключены из Git. Исходники агентов находятся
в `packages/dev-agents/`. После подготовки перезапустите агентский клиент.

После клонирования репозитория или получения изменений `skills-lock.json` выполните:

```bash
npx skills@latest experimental_install
```

Команда читает `skills-lock.json` и восстанавливает скиллы в `.agents/skills/`
без интерактивных подтверждений. Ссылки в `.claude/skills/` эта команда не создаёт.

Для восстановления используется именно `experimental_install`: обычная команда
`install` является псевдонимом `add` и требует указать источник.

## Добавить скилл с фиксацией версии

Для воспроизводимой установки закрепляйте источник на полном SHA Git-коммита
из 40 символов. Например, текущий SHA ветки по умолчанию репозитория Relay
можно получить командой:

```bash
git ls-remote https://github.com/oim-dev/relay.git HEAD
```

Подставьте SHA из первой колонки вместо `<commit-sha>`:

```bash
npx skills@latest add "oim-dev/relay#<commit-sha>" --skill relay -y
```

Для другого скилла замените `oim-dev/relay` на его репозиторий, а `relay` — на имя
скилла. Используйте проектную установку без `-g`; флаг `-y` отключает подтверждения.

После успешной установки CLI автоматически создаёт или обновляет `skills-lock.json`:

- `source` и `sourceType` описывают источник;
- `skillPath` указывает путь к скиллу в репозитории;
- `ref` сохраняет указанный SHA коммита;
- `computedHash` содержит SHA-256 содержимого скилла.

Поле `computedHash` само по себе не закрепляет версию. Для точного восстановления
нужен `ref` с SHA коммита: имя ветки может указывать на новые коммиты, а тег может
быть перемещён. Если `ref` отсутствует, восстановление использует актуальное
содержимое ветки по умолчанию.

## Обновить скилл

### Скилл с закреплённым SHA

Выберите новый коммит и повторите установку с его полным SHA:

```bash
npx skills@latest add "oim-dev/relay#<new-commit-sha>" --skill relay -y
```

CLI обновит установленный скилл, `ref` и `computedHash` в `skills-lock.json`.
Обычный `update` сохраняет закреплённый SHA и не переключает скилл на последний коммит.

### Скилл без закреплённого SHA

Обновить один проектный скилл из его источника:

```bash
npx skills@latest update relay -p -y
```

Обновить все проектные скиллы:

```bash
npx skills@latest update -p -y
```

Флаг `-p` ограничивает обновление скиллами проекта, `-y` отключает подтверждения.
Команда также обновляет `skills-lock.json`.

После добавления или обновления проверьте изменения `skills-lock.json` и сохраните
их в Git. Остальные разработчики применяют обновлённый файл командой
`npx skills@latest experimental_install`.
