# Сопровождение проектных агентов

Применяй корневой `AGENTS.md`. Инструкция относится также к выходам `.opencode/agents/`,
`.claude/agents/`, `.codex/agents/`, `opencode.json`, `.claude/settings.json`,
`.codex/config.toml` и `agents-lock.json`.

- `src/manifest.json` — реестр; `src/*.md` — полные роли. Сценарии работы с Relay
  находятся в `playbooks/relay/`, правила пути — в соответствующих `AGENTS.md`.
- Рабочие требования и состояние проекта принадлежат Relay. В пакете описывается
  способ работы, а не копия проектной памяти. Установленный скилл не редактируй.
- Основные обязанности главного, фоновое делегирование, границы записи воркеров и
  порядок приёмки должны быть видны из профилей без обязательного чтения всей библиотеки.
- Пути в профилях указывай от корня репозитория. В Markdown-ссылках сценариев используй
  относительный путь от документа. Проверь наличие источников, не ссылайся на будущие файлы
  как на уже существующие обязательные инструкции.
- Генерируемые файлы и lock вручную не редактируй. После готовности всех источников
  один исполнитель запускает из корня `pnpm run agents:build`, затем `pnpm run agents:check`.
  Конкурирующая генерация не поддерживается.
- Сохраняй одинаковое содержание роли для трёх сред. Метаданные и способ выбора главного
  могут различаться. В Claude фон закрепляется у воркеров, не у главной сессии.
- Модели и дополнительные ограничения инструментов не фиксируются. Возможности среды
  наследуются; правила ответственности не являются техническими ACL.
- При изменении формата OpenCode применяй `customize-opencode` и официальную схему.
  Форматы Claude Code и Codex сверяй с их текущей документацией и установленными версиями.
- Достаточны сборка, read-only проверка актуальности и необходимых ссылок. Не добавляй
  отдельную тестовую инфраструктуру или проверки точных формулировок промптов.
  После подключения отдельно проверь выбор главного и одно фоновое поручение в каждой среде.
- После изменений конфигураций OpenCode требуется перезапуск. Уже работающие агенты
  не получают новый профиль от замены файла. Указывай это в результате настройки.
